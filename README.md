# Product Management Skills

> A Crew44 agent packaged from https://github.com/phuryn/pm-skills

A marketplace of 65 product-management skills spanning discovery, strategy, execution, launch, and growth — assumption mapping, prioritization, PRDs and user stories, positioning and market sizing, metrics and north-star, A/B and cohort analysis, pricing and growth loops. Encodes proven PM frameworks (Torres, Cagan, Savoia) as guided step-by-step workflows for structured product decisions.

This repository is a [Crew44](https://github.com/getcrew44/crew44)-compatible
agent. Crew44 is a local-first orchestrator for running specialist AI agents
on your own machine; install this agent from the Crew44 app's **Recruit**
tab.

## What's inside

- `INSTRUCTIONS.md` — the agent's entrypoint and role.
- `crew44-agent.json` — the manifest the Crew44 app reads to install this agent.
- `upstream/` — the vendored upstream project, pinned to a commit.
